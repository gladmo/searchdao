# 寻道修仙 - 修仙放置游戏

一个简单有趣的修仙题材放置类小游戏。通过砍树获取装备，提升战力，体验修仙之路！

## ✨ 游戏亮点

- 🎮 **简单易上手**：点击砍树即可开始游戏，无复杂操作
- ⚔️ **装备收集**：12种装备类型，4种品质等级，随机掉落充满惊喜
- 🆙 **等级系统** 🆕：通过砍树升级，解锁更强装备，体验10个修仙境界
- 💪 **战力成长** 🆕：等级和战力相互促进，战力越高掉落越好
- 📊 **智能对比**：获得同类装备时自动弹出对比界面，属性差异一目了然  
- 🔄 **自动化**：支持自动装备模式，解放双手
- 💾 **进度保存**：使用LocalStorage自动保存游戏进度
- 🎨 **精美界面**：修仙风格UI设计，emoji装备图标生动有趣

## 🎮 游戏特性

### 核心系统

- **砍树系统**：点击砍树按钮或直接点击树木进行砍伐
  - 每次砍树消耗1点修为（体力）
  - 每次砍树随机获得一件装备
  
- **等级系统** 🆕：通过砍树积累经验提升等级
  - 每砍一次树获得1点经验
  - 升级所需经验 = 当前等级 × 10
  - 等级提升后装备属性倍率增加10%
  - 共10个修仙境界：炼气期、筑基期、金丹期、元婴期、化神期、炼虚期、合体期、大乘期、渡劫期、飞升期
  - 升级时显示✨动画效果
  
- **装备系统**：12种装备类型，每种装备独立占据一个槽位
  - ⚔️ 武器、🪖 头盔、🛡️ 护甲、🥾 靴子
  - 🔗 腰带、💪 护腕、📿 项链、💍 戒指
  - 🔮 玉佩、💎 宝石、📜 符咒、🥚 灵兽蛋
  
- **品质系统**：4种装备品质，影响属性数值
  - 普通 (基础掉落率 50%)
  - 精良 (基础掉落率 30%)  
  - 稀有 (基础掉落率 15%)
  - 史诗 (基础掉落率 5%)
  - **战力加成** 🆕：战力越高，稀有装备掉落率越高
  
- **属性系统**：每件装备包含四维属性
  - 攻击、生命、防御、敏捷
  - 装备等级越高，属性越强
  - **等级加成** 🆕：角色等级越高，装备属性倍率越高
  - **战力加成** 🆕：战力越高，装备属性数值越好（最高+50%）
  - **属性波动** 🆕：等级提升增加属性随机波动范围（±40% → ±80%）
  
- **战力计算**：综合评估角色实力
  - 战力 = 攻击 + 生命/10 + 防御×2 + 敏捷
  - 战力影响装备掉落品质和属性强度
  
- **修为系统**：类似体力值的资源管理
  - 每次砍树消耗1点修为
  - 每秒自动恢复1点修为
  - 最大修为值为50点
  
- **装备对比**：智能装备替换系统
  - 获得相同类型装备时自动弹出对比窗口
  - 显示新旧装备属性差异（红色▼表示降低，绿色▲表示提升）
  - 可选择装备新装备或保留旧装备
  - 未装备的装备会自动分解获得灵石
  
- **自动装备**：可开启自动模式
  - 自动替换低品质或低战力的装备
  - 自动分解不需要的装备
  
- **分解系统**：资源回收机制
  - 点击已装备的装备可手动分解
  - 分解装备获得灵石（游戏货币）
  - 分解次数和收益在界面底部显示

## 🎯 游戏玩法

### 快速开始

1. **开始砍树**
   - 点击中间的树木图标 🌳 或底部的砍树按钮 🪓
   - 每次砍树消耗1点修为，获得1件随机装备

2. **管理装备**
   - 新获得的装备会自动装备到对应槽位
   - 如果槽位已有装备，会弹出对比窗口让你选择
   - 查看属性变化（绿色▲代表提升，红色▼代表降低）
   - 选择"装备新的"或"保留旧的"

3. **分解装备**
   - 点击已装备的装备图标可以分解
   - 分解获得灵石（货币）
   - 灵石数量显示在左上角 💎

4. **提升等级和战力** 🆕
   - 持续砍树积累经验值升级
   - 等级提升后装备掉落属性更强
   - 战力越高，装备品质和属性越好
   - 战力显示在右上角 🔥
   - 合理搭配装备以获得最大战力

5. **自动模式**（可选）
   - 点击底部"自动"按钮开启自动装备模式
   - 系统会自动选择战力更高的装备
   - 自动分解低品质装备

### 游戏技巧

- 📈 **优先高品质**：史诗 > 稀有 > 精良 > 普通
- 🎯 **平衡发展**：尽量让所有槽位都装备上装备
- 💡 **战力优先**：对比时优先选择战力提升更多的装备
- ⚡ **合理使用修为**：修为会自动恢复，保持持续砍树即可
- 🔄 **等级与战力循环** 🆕：等级提升→装备更强→战力更高→掉落更好→战力再提升
- 🎲 **高战力高回报** 🆕：战力达到1000、5000、10000等门槛时，稀有装备掉落率显著提升
