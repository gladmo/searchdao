# searchdao

寻道大千 - 修仙放置游戏

## 在线游玩

访问 GitHub Pages: [https://gladmo.github.io/searchdao/](https://gladmo.github.io/searchdao/)

## 本地运行

直接在浏览器中打开 `index.html` 文件即可游玩。

## 游戏特点

- 🌳 砍树获取装备
- ⚔️ 装备属性系统
- 🔄 自动装备与分解
- 💪 修为（体力）恢复机制
- 📊 战力计算系统

## 部署

本项目使用 GitHub Actions 自动部署到 GitHub Pages。每次推送到 `main` 或 `master` 分支时会自动触发部署。
