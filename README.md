# 寻道大千 - 修仙放置游戏

一个简单有趣的修仙题材放置类小游戏，核心玩法包括砍树、装备掉落、属性提升等。

## 在线游玩

访问 GitHub Pages: [https://gladmo.github.io/searchdao/](https://gladmo.github.io/searchdao/)

## 本地运行

直接在浏览器中打开 `index.html` 文件即可游玩。

## 游戏特点

- 🌳 砍树获取装备
- ⚔️ 装备属性系统
- 🔄 自动装备与分解
- 💪 修为（体力）恢复机制
- 📊 战力计算系统

## 部署

本项目使用 GitHub Actions 自动部署到 GitHub Pages。每次推送到 `main` 或 `master` 分支时会自动触发部署。

## 🎮 游戏特性

- **砍树系统**：点击砍树按钮或直接点击树木进行砍伐
- **装备系统**：随机掉落12种装备类型，4种品质等级
  - 普通 (50%)
  - 精良 (30%)
  - 稀有 (15%)
  - 史诗 (5%)
- **属性系统**：攻击、生命、防御、敏捷
- **战力计算**：战力 = 攻击 + 生命/10 + 防御×2 + 敏捷
- **体力系统**：每次砍树消耗1点体力，每秒恢复1点，最大50点
- **自动装备**：可开启自动分解低品质装备
- **分解系统**：点击装备可分解获得灵石

## 🚀 本地运行

直接打开 `index.html` 文件，或使用本地服务器：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`

## 📦 部署

项目配置了 GitHub Actions 自动部署到 GitHub Pages。

当代码推送到 `main` 分支时，会自动触发部署流程。

## 🎯 游戏玩法

1. 点击中间的树木或底部的砍树按钮
2. 消耗体力获得随机装备
3. 点击装备可以分解获得灵石
4. 开启自动装备功能可自动替换低品质装备
5. 不断提升战力！
