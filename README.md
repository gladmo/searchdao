# searchdao - 寻道大千

一款放置类修仙游戏，灵感来自"寻道大千"。

## 游戏特色

### 核心玩法
- **资源采集**: 通过砍树获得木材和经验
- **装备系统**: 强化武器和护甲，随机品质（普通、精良、稀有、史诗、传说）
- **角色成长**: 升级获得更多战力
- **灵宠系统**: 召唤和培养灵宠，增强战力
- **技能升级**: 提升剑法等技能增加战力
- **竞技场PVP**: 与对手战斗获取灵石奖励
- **限时活动**: 双倍经验等活动

### 游戏系统

#### 资源系统
- 砍树获得木材（冷却时间2秒）
- 随机掉落灵石（30%概率）
- 经验值自动转化为等级

#### 装备系统
- 消耗50木材强化装备
- 5种品质等级，影响战力加成
- 品质概率：普通50%、精良30%、稀有15%、史诗4%、传说1%

#### 灵宠系统
- 消耗50灵石召唤灵宠
- 灵宠可升级提升战力
- 5级以上灵宠提供被动资源收益

#### 技能系统
- 基础剑法和御剑术
- 升级消耗灵石，提升战力
- 技能等级越高，升级成本越高

#### 竞技场系统
- 与随机对手战斗
- 胜利获得灵石奖励
- 记录胜负场次

#### 限时活动
- 双倍经验活动（5分钟）
- 活动结束后2分钟重新开启

## 如何开始

1. 打开 `index.html` 文件
2. 开始你的修仙之旅！
3. 游戏进度自动保存到浏览器本地存储

## 技术栈

- 纯HTML/CSS/JavaScript
- LocalStorage 用于存档
- 响应式设计支持移动端
