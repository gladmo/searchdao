# 寻道大千 - 修仙放置游戏

一个简单有趣的修仙题材放置类小游戏。通过砍树获取装备，提升战力，体验修仙之路！

## ✨ 游戏亮点

- 🎮 **简单易上手**：点击砍树即可开始游戏，无复杂操作
- ⚔️ **装备收集**：12种装备类型，4种品质等级，随机掉落充满惊喜
- 📊 **智能对比**：获得同类装备时自动弹出对比界面，属性差异一目了然  
- 🔄 **自动化**：支持自动装备模式，解放双手
- 💾 **进度保存**：使用LocalStorage自动保存游戏进度
- 🎨 **精美界面**：修仙风格UI设计，emoji装备图标生动有趣

## 🎮 游戏特性

### 核心系统

- **砍树系统**：点击砍树按钮或直接点击树木进行砍伐
  - 每次砍树消耗1点修为（体力）
  - 每次砍树随机获得一件装备
  
- **装备系统**：12种装备类型，每种装备独立占据一个槽位
  - ⚔️ 武器、🪖 头盔、🛡️ 护甲、🥾 靴子
  - 🔗 腰带、💪 护腕、📿 项链、💍 戒指
  - 🔮 玉佩、💎 宝石、📜 符咒、🥚 灵兽蛋
  
- **品质系统**：4种装备品质，影响属性数值
  - 普通 (50% 掉落率)
  - 精良 (30% 掉落率)  
  - 稀有 (15% 掉落率)
  - 史诗 (5% 掉落率)
  
- **属性系统**：每件装备包含四维属性
  - 攻击、生命、防御、敏捷
  - 装备等级越高，属性越强
  
- **战力计算**：综合评估角色实力
  - 战力 = 攻击 + 生命/10 + 防御×2 + 敏捷
  
- **修为系统**：类似体力值的资源管理
  - 每次砍树消耗1点修为
  - 每秒自动恢复1点修为
  - 最大修为值为50点
  
- **装备对比**：智能装备替换系统
  - 获得相同类型装备时自动弹出对比窗口
  - 显示新旧装备属性差异（红色▼表示降低，绿色▲表示提升）
  - 可选择装备新装备或保留旧装备
  - 未装备的装备会自动分解获得灵石
  
- **自动装备**：可开启自动模式
  - 自动替换低品质或低战力的装备
  - 自动分解不需要的装备
  
- **分解系统**：资源回收机制
  - 点击已装备的装备可手动分解
  - 分解装备获得灵石（游戏货币）
  - 分解次数和收益在界面底部显示

## 🎯 游戏玩法

### 快速开始

1. **开始砍树**
   - 点击中间的树木图标 🌳 或底部的砍树按钮 🪓
   - 每次砍树消耗1点修为，获得1件随机装备

2. **管理装备**
   - 新获得的装备会自动装备到对应槽位
   - 如果槽位已有装备，会弹出对比窗口让你选择
   - 查看属性变化（绿色▲代表提升，红色▼代表降低）
   - 选择"装备新的"或"保留旧的"

3. **分解装备**
   - 点击已装备的装备图标可以分解
   - 分解获得灵石（货币）
   - 灵石数量显示在左上角 💎

4. **提升战力**
   - 通过装备更高等级、更高品质的装备提升战力
   - 战力显示在右上角 🔥
   - 合理搭配装备以获得最大战力

5. **自动模式**（可选）
   - 点击底部"自动"按钮开启自动装备模式
   - 系统会自动选择战力更高的装备
   - 自动分解低品质装备

### 游戏技巧

- 📈 **优先高品质**：史诗 > 稀有 > 精良 > 普通
- 🎯 **平衡发展**：尽量让所有槽位都装备上装备
- 💡 **战力优先**：对比时优先选择战力提升更多的装备
- ⚡ **合理使用修为**：修为会自动恢复，保持持续砍树即可
